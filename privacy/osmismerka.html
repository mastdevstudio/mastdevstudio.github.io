Generátor Osmisměrky

ČeskyEnglish

Zásady soukromí

Datum účinnosti: 12. října 2026

1. Přehled

Generátor Osmisměrky je slovní hra pro iOS, macOS a tvOS vyvíjená studiem Mast Dev Studio. Respektujeme soukromí uživatelů a minimalizujeme práci s daty.

2. Jaká data zpracováváme

Mast Dev Studio prostřednictvím aplikace Generátor Osmisměrky nesbírá ani nepřijímá osobní údaje uživatelů. Rozehraná hra, nastavení, stav dokončení a případná vlastní tajenka se ukládají pouze místně v zařízení uživatele.

3. Připojení k internetu

Hra funguje plně offline. Není vyžadována registrace ani přihlášení.

4. Export a sdílení PDF

Na podporovaných zařízeních může uživatel vytvořit, uložit, vytisknout nebo sdílet osmisměrku jako PDF. Soubor vzniká místně v zařízení. Pokud se jej uživatel rozhodne sdílet, zpracuje jej zvolená systémová služba nebo aplikace třetí strany podle vlastních podmínek ochrany soukromí.

5. Třetí strany

Aplikace nevyužívá analytické ani reklamní SDK třetích stran.

Privacy policy

Effective date: October 12, 2026

1. Overview

Generátor Osmisměrky is an iOS, macOS, and tvOS word game developed by Mast Dev Studio. We respect user privacy and keep data handling to the minimum.

2. Data We Process

Mast Dev Studio does not collect or receive personal user data through Generátor Osmisměrky. Game progress, settings, completion status, and any custom secret phrase are stored only locally on the user's device.

3. Internet Connection

The game works fully offline. No registration or sign-in is required.

4. PDF Export and Sharing

On supported devices, users may create, save, print, or share a puzzle as a PDF. The file is created locally. If the user chooses to share it, the selected system service or third-party app handles the file under its own privacy terms.

5. Third-Party Services

The app does not use third-party analytics or advertising SDKs.
